# dar4datascience.com

Personal website of Daniel Amieva Rodriguez — Senior Data Engineer. Built with Next.js (App Router, TypeScript, Tailwind CSS) and deployed to Cloudflare Workers via OpenNext. Includes an MCP endpoint at `/mcp` exposing the verified profile as JSON-RPC tools.

All factual content lives in `src/data/profile.ts` — edit there only.

See [AGENTS.md](./AGENTS.md) for environment setup, npm scripts, and deploy instructions.
